How this version is put together

01

One file per page

Every page in the pages folder is a complete HTML file, and each game keeps its CSS and script inside it.

02

One list to rule the menu

The page list at the top of the script builds the side menu, the drop-down, the search and these cards.

03

A folder for releases

Each changelog entry is a JSON file. The page reads the folder index and renders the timeline.

Ready for GitHub Pages

There is no build step. Upload this folder to a repository, switch Pages on, and the same files are live. The setup guide is written for a first repository.
