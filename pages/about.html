About

A sample info page. Copy the file, change the words, keep the structure.

Everything on this site lives in one place: a folder of pages. Some are games you can play straight from the menu, others are pages like this where you write down whatever is worth keeping.

There is no editor to learn and nothing to publish separately. A page is a file, the page list gives it a name and a link, and the menu picks it up automatically.

How the site is put together

Pagespages/ — info pages and games side by side
Page listassets/app.js — one entry per page
Settingsdata/site.json — name, tagline, contact email, menu default
Releaseschangelog/ — one JSON file per release
ContentWritten directly in the HTML, no database

Why keep it this simple

Files stay readable, changes stay small, and every page can be read on its own years from now. It also means the whole site can live in a normal repository, with the home page, the readme and the pages folder in one place.
